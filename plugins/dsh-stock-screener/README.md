# 选股器（dsh-stock-screener）

安装包从 [GitHub Release](https://github.com/jx62257070/tauri-plugin/releases) 下载，文件名形如 `dsh-stock-screener-<版本>.zip`（版本以 Release 页面为准）。

一句话：把「按条件在全市里捞票」的三件工具收进一个可选插件 —— **基础筛选**（全市场条件筛选 + MA5/20 金叉死叉回测）、**信号扫描**（股票池 × MA/MACD/RSI/BOLL 八种技术信号）、**尾盘选股**（市值/量比/涨幅/换手过滤 + 分时强度精筛）。自宿主 v3.3.0 起由内置页改为插件分发，装不装、卸不卸都随你。

## 功能特性

- **基础筛选**：全市场快照按涨幅 / 换手率 / 量比 / PE(TTM) 条件筛选，按成交额降序取前 N；任意结果行可一键带入「简单回测」。
- **简单回测**：单票 MA5/20 金叉死叉策略 vs 买入持有基准（近一年日 K、含手续费），输出总收益、胜率、最大回撤、交易次数与权益曲线对比。
- **信号扫描**：股票池五个来源（自选股 / 手选板块 / 榜单 TopN / 涨停·强势池 / 盘口异动池）× 八种信号模板多选，并发扫描支持取消、进度与边扫边出结果。
- **尾盘选股**：全市场按流通市值 / 量比 / 涨幅 / 换手率 / ST 基础过滤后，逐票拉分时按「分时强度」（分时价位于均价上方的时间占比）精筛。
- **Agent 工具**：为应用内置 Agent 贡献 `run_backtest` 工具（单票回测），插件停用即失效。

## 安装

前置：已安装 **[WHF 股票看板](https://github.com/WHF293/whf-stock-board)**（v3.3.0 及以上）。

1. 打开应用，进入「插件工坊」（应用内的插件管理入口）；
2. 选择「导入插件」，选中刚下载的 zip 安装包；
3. 导入后启用，左侧导航会出现「选股器」（路径 `/screener`，与原内置页一致）。

卸载：在「插件工坊」里对该插件点卸载即可，本插件不落任何本地数据表，卸载即彻底移除。

## 快速上手

1. **基础筛选**：填条件（留空不过滤）→ 点「开始筛选（全市场）」；点结果行的「回测」把标的带入回测卡；
2. **信号扫描**：选股票池来源与信号模板 → 点「开始扫描」；结果行单击开右侧详情、双击进详情页；
3. **尾盘选股**：交易日 14:30 后效果最佳 → 点「开始分析（全市场）」，按分时强度降序看强势股；
4. 全部接口都是**重接口**（全市场快照 / 逐票日 K / 逐票分时），只在你点击时发起，请勿频繁连点。

## 与内置版的差异

| 项 | 内置版（≤ v3.2.0） | 插件版 |
| --- | --- | --- |
| 页签配置 | 页签显隐 / 顺序可配置（宿主 store） | 固定三页，不可配置 |
| 扫描结果「加自选」 | 支持（写宿主自选股） | **移除**（宿主自选股对插件只读；请打开个股后在自选股页添加） |
| 回测权益曲线 | ECharts | 内置轻量 SVG 双线图（形状对比，无坐标刻度） |
| 回测 K 线缓存 | SQLite 落库（跨会话） | 会话内缓存（应用重启后首次回测重新取一次） |
| Agent `run_backtest` | 宿主 stock-sdk 服务器自带 | 随本插件提供（装了才有） |

## 数据与隐私

- **数据来源**：全市场快照与板块 / 股池走东方财富（经宿主上游通道，`push2` 系自动改道 `push2delay`）；日 K 走新浪财经（不复权）；分时与批量行情走腾讯（JSONP 直连）。
- **联网时机**：**只由你点击触发**（筛选 / 扫描 / 回测 / 分析按钮），不轮询；信号扫描并发 3、尾盘分时并发 2、全市场快照分页并发 3，对上游保持克制。
- **本地存储**：无数据表、无持久化 —— 扫描与回测结果只在页面内存里，刷新即清。
- **已知限制**：新浪日 K 为不复权，除权日附近指标与回测结果为近似口径（与内置版一致）。
