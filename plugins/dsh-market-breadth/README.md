# 市场宽度（dsh-market-breadth）

安装包从 [GitHub Release](https://github.com/jx62257070/tauri-plugin/releases) 下载，文件名形如 `dsh-market-breadth-<版本>.zip`（版本以 Release 页面为准）。

一句话：看「多少只股票在涨」而不只是「指数涨没涨」——本插件提供 A 股市场宽度的当日概览（涨跌家数 / ARMS 现值 / 活跃占比）与六大经典广度指标副图（ADL 腾落线 / ADR 涨跌比率 / OBOS 超买超卖 / ARMS / MCO 麦克莱伦震荡 / 活跃占比，口径对齐通达信），是发现「指数与个股背离」的主力工具。

## 功能特性

- **当日概览**：上涨 / 平盘 / 下跌家数、上涨量 / 下跌量（手）、ARMS 现值五档状态（强势 / 偏强 / 平衡 / 偏弱 / 弱势）、活跃股家数与占比（换手率 > 5% 口径）。
- **六大广度指标副图**：ADL（含 MA10）、ADR（N=10）、OBOS（N=10，含 MA6）、ARMS（MA21，含 y=1 基准线）、MCO（EMA19−EMA39，含信号线）、活跃占比；视图档位近 60 日 / 近 120 日 / 全部积累。
- **本地逐日积累**：历史没有免费上游数据源，**无法回填** —— 页面挂载期间每 30 秒拉一轮全市场快照（东财源，小并发分页，并发 3 的频率红线内）积累分钟点；行情时间 ≥ 15:00 视为收盘定稿，自动聚合为当日日 bar 落本地库（`ctx.db`，Tauri 端 SQLite / 浏览器端 JSON 仿真）。周末 / 节假日打开也会把最近交易日的 bar 补齐定稿。
- **总结**：点击「总结」弹窗展示六大指标的最新解读（一句白话 + 涨跌语义色）；弹窗内**日期选择器**限定为「已采集到数据的日期」（默认最新），选定后展示该日的总结。
- **刷新**：点击「刷新」重取当前选中日期的数据 —— 选中日为今天时重拉一轮全市场快照 ingest（同分钟覆盖 + 收盘定稿幂等落库）；选中日为历史日时上游无数据可回源，改为从本地分钟点末点**重算该日 bar 并覆盖落库**（本地库是单一事实源）。刷新中按钮置 loading 防重复点击。
- **AI 分析**：点「AI 分析」把最新截面 + 近 10 / 30 日趋势组装成自包含提示词发往 Agent 分析窗口（需宿主已配置模型；Agent 服务缺席时按钮自动隐藏）。政策日历 / 地缘部分由提示词驱动 Agent 自行查证。
- **Agent 工具**：向内置 Agent 贡献只读 MCP 服务器 `breadth-data`：`get_breadth_snapshot`（当日宽度统计 + 六指标最新值，数据陈旧 >60s 自动重拉快照）与 `get_breadth_history`（近 N 日日 bar 序列，默认 30 上限 120）。

## 数据口径

- ARMS = (上涨家数 ÷ 下跌家数) ÷ (上涨成交量 ÷ 下跌成交量)，成交量取手数，与通达信主流一致；分母为 0 展示「--」。
- 涨跌幅非有限数值（停牌 / 异常）的标的剔除，不计家数不计量。
- 活跃占比分母为换手率有效（正常交易）家数；ADL 起点为本地首条 bar，仅具相对意义。

## 安装

前置：已安装 **[WHF 股票看板](https://github.com/WHF293/whf-stock-board)**。

1. 打开应用，进入「插件工坊」；选择「安装自定义插件」→「从 zip 包安装」，选中下载的 zip；
2. 安装后左侧导航出现「市场宽度」（路径 `/market-breadth`，与宿主历史路径一致，老书签直达）。

## 历史数据说明

- 本插件的数据表是全新的 `ctx.db` 表（`plugin_dsh_market_breadth_minute_point` / `plugin_dsh_market_breadth_day_bar`），**首版不做宿主旧版 appStorage 数据的迁移** —— 历史宽度数据无上游源、本就不可回填，安装后由快照重新逐日积累即可（首个交易日收盘后出第一根 bar；ADR / OBOS 约 10 日、ARMS MA21 约 21 日、MCO 约 50 日趋稳）。
- 日 bar 滚存最近 250 个交易日（约一年），分钟点仅保留最近 3 日（bar 定稿后旧分时无用）。

## 频率纪律

全市场快照重接口只在两处触发：页面挂载期间盘中 30s 轮询（交易窗口外暂停、挂载必跑一次）与「刷新」按钮 / Agent 快照工具的按需重拉。并发固定 3 / 每页 500（东财反爬红线内），全插件共用一个 SDK 实例串行错峰。
