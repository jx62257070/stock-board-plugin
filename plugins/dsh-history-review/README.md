# 历史牛熊复盘（dsh-history-review）

安装包从 [GitHub Release](https://github.com/jx62257070/tauri-plugin/releases) 下载，文件名形如 `dsh-history-review-<版本>.zip`（版本以 Release 页面为准）。

一句话：把 2000 年以来的大级别牛熊行情做成可对标的「模式库」——左侧导航新增「历史牛熊复盘」页面，历史牛市 / 历史熊市每轮行情一份完整档案（阶段拆解 / 事件时间线 / 多因子错配画像），页面上的涨幅 / 回撤 / 时长全部由指数月 K 回算，配合模式库的七轮横向对比与可复用规律，用于识别当下行情处于历史的哪一段。

## 功能特性

- **历史牛市 / 历史熊市**：各七轮行情档案（核心资产·白酒抱团、国有股减持大熊市等），统计条（区间最大涨幅 / 最大回撤 / 至顶或至底时长）由月 K 回算；行情四阶段图（SVG 手绘，阶段色带随宿主主题与明暗自动跟随）标注起点 / 顶点 / 低点；阶段明细、事件时间线（五类标注 · 区分预期与落地）、见顶瓦解 / 见底出清复盘卡。
- **模式库**：牛熊七轮横向对比表（可排序）、可复用规律卡、四轮机构抱团行情的看板预警能力对比（来源：豆包复盘框架）。
- **零联网阅读**：首次进入自动同步新浪指数月 K（上证指数 / 沪深300 / 创业板指，串行 500ms 错峰）落插件本地快照，此后重进页面零联网；「更新到最新」手动增量刷新。
- **数据自持**：快照落在插件独立存储（`ctx.storage`），与宿主及其他插件天然隔离；卸载插件数据保留，重装恢复。

## 口径与边界

- 月 K 来源为新浪 `quotes.sina.cn`（经宿主 `app:http` 受控通道，`sina.cn` 在宿主白名单内）；不用东财行情域（宿主红线）。
- 页面所有数字由 `judge.ts` 纯函数从月 K 回算，文案只做定性结论；复盘观点仅供参考，不构成投资建议，也不能预测崩盘或见底的具体时点。
- 阶段区间 / 轮次窗口为复盘档案的硬编码观点（不可变历史），关键位月份以数据为准。

## 安装

前置：已安装 **[WHF 股票看板](https://github.com/WHF293/whf-stock-board)**（v4.28.0 起，旧版本宿主行情全景页内置「历史复盘」页签、无需安装）。

1. 打开应用，进入「插件工坊」→「插件清单」的「未安装 / 全部」视图（或「安装自定义插件」→「从 zip 包安装」选中下载的 zip）；
2. 安装后从左侧导航「插件」组进入「历史牛熊复盘」。原行情全景页的「历史复盘」页签自宿主 v4.28.0 起移除。

## 卸载

插件工坊里一键停用 / 卸载即可：本插件无 `ctx.db` 数据表，唯一持久化是插件 storage 里的月 K 快照（重装后自动恢复）；彻底清除数据可在卸载弹窗选择一并删除。
