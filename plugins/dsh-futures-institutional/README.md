# dsh-futures-institutional（期货·机构行为）

左侧导航新增「机构行为」看板（沿用宿主 `/futures/institutional` 路径，宿主删自带页后由本插件接管）：
中金所 CCPM 成交持仓排名（每日披露 CSV，GBK 编码，仅 HTTP 无 HTTPS）的多空席位行为观测。

## 功能

- **筛选器**：品种（IF/IH/IC/IM 股指 + T/TF/TS/TL 国债）/ 三档合并口径（单合约、同品种合并、全股指合并）/ 合约 / 交易日 / 席位搜索
- **概览指标卡**：上榜总多 / 总空 / 成交量 / 多空净差 / 席位数
- **上榜会员总表**：多空持仓、增减、净持仓与**行为标注**（做多 / 做空 / 对冲，算法自动识别；选中行席位名高亮，行展开看席位跨合约分解）
- **席位画像**：选中席位的净持仓锚点（净增减胶囊）、多空双格与增减、结构条（聚合口径为上榜合约覆盖进度、单合约为多空占比）、行为判定依据与其余上榜会员对照
- **多空并排柱状**（|净持仓| 前 10）与**席位净持仓时序**（近 20 个披露日，SVG 轻量图）
- **衍生榜单**：净多 / 净空 / 多空增减仓 TOP
- **移仓换月**（折叠）：近月减仓 + 次月同向增仓 ≥100 手标记疑似移仓
- **AI 分析**：把当前口径席位数据摘要交给 Agent 分析窗口（宿主未提供 `app:agent-ask` 时按钮自动隐藏）
- **Agent MCP 工具**：贡献 `futures-ccpm` 服务器，两只只读工具（读本地缓存，不触网）
  - `get_ccpm_summary`：指定品种（可选交易日）的合约合计与席位多空标注摘要（TOP N 控 token）
  - `get_ccpm_history`：指定席位的合并净持仓时序

## 数据与同步

- 上游：`http://www.cffex.com.cn/sj/ccpm/{yyyymm}/{dd}/{product}_1.csv`（静态文件，非披露日 302 错误页；
  经宿主 `app:http` 走 Tauri 直连 / 浏览器代理，白名单已含 `cffex.com.cn`）
- **首次使用请点「同步历史」**：一次性回溯约 60 个自然日 × 8 个品种回填本地库
  （同一上游并发 ≤3、请求间 ≥500ms 错峰；非轮询，不会自动跑）
- 缓存语义：披露日定稿数据（正缓存）永久有效；非披露日探测落空（负缓存）按 30 分钟 TTL 过期
- ⚠️ **旧版宿主 SQLite 表（`ccpm_day_cache`）的数据不做迁移**——中金所历史文件可随时重取，
  装上本插件后点一次「同步历史」即可等价重建本地库。插件数据落在独立表
  `plugin_dsh_futures_institutional_ccpm_day_cache` / `..._sync_meta`（Tauri 端 SQLite、浏览器端本地仿真），与宿主旧表互不影响
- 页面日常浏览优先读本地缓存，缓存未命中才回源；「刷新」按钮强制回源当日

## 口径与风险（常驻提示，页面同款）

数据为中金所披露的**代客经纪业务**合并持仓（会员全部客户总和，不是单一机构）；
仅披露达标 / 前 20 会员；净持仓为收盘隔夜快照；空头持仓 ≠ 看空（含套保盘）；
行为标签为算法自动识别，仅供分析，不构成投资建议。

## 移植说明

页面、解析、判定逻辑自宿主 `FuturesInstitutionalView` / `futures-ccpm.api.ts` / `parse-ccpm-csv.ts` /
`ccpm-compute.ts` 等价移植（判定纯函数逐行同口径）；持久层由宿主 SQLite 直连改为 `ctx.db`；
网络由 `proxy-fetch` 改为 `app:http`。图表为 SVG 轻量实现（插件不带 ECharts 依赖）。
