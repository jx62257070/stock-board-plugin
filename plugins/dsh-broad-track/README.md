# 宽基跟踪（dsh-broad-track）

安装包从 [GitHub Release](https://github.com/jx62257070/tauri-plugin/releases) 下载，文件名形如 `dsh-broad-track-<版本>.zip`（版本以 Release 页面为准）。

一句话：国家队（中央汇金 / 汇金资管 / 证金 / 梧桐树 / 国新等）在 A 股的主要动作是**申购宽基 ETF**而不是买个股 —— 本插件跟踪宽基 ETF 的**逐日份额（真实申赎）**为主口径，配合日频二级市场资金流与季频披露，用**披露锚点 + 报告期后净申购分摊**预估其持仓，并按「连续大额申赎 + 指数位置」等形态推定它的进出场。

## 功能特性

- **宽基 ETF 清单**：17 只主流宽基 ETF（沪深300 × 4 / 上证50 × 2 / 中证500 × 3 / 中证1000 × 4 / 科创50 × 2 / 创业板 × 2），覆盖沪深两个市场；6 个宽基指数快照同行展示。
- **⭐ 逐日份额序列（主口径）**：从交易所官方披露拉取**每日 ETF 总份额**，算出「当日份额变动 × 当日收盘价 = 估算净申赎金额」。份额变动是**真实的申购 / 赎回**（一篮子实物申赎），国家队的大额动作只能在这里看到 —— 二级市场资金流只是「谁在买卖」，噪音极大。
- **增量入库**：历史份额**落本地库**，已入库的日期不再回源；分批回填可断点续传（每批落一次库），批与批之间的衔接日也能拿到上一批末尾的份额算变动。
- **进场 / 退场信号（份额口径）**：按**方向段**判定（连续同向的份额变动算一段，一次战役 = 一个信号，不是每天一次）：「进场」= 连续净增 + 累计净申购达标 + 指数处历史低位；「退场」= 连续净减 + 累计净赎回达标 + 指数处历史高位。
- **信号回测**：按**波段**（不按天）统计每个信号的次日收益、持有期收益与胜率。
- **日频资金流跟踪**（辅助列）：逐只 ETF 的主力 / 超大单 / 大单 / 中单 / 小单净流入（东财 fflow），宽基口径合计与近 5 日趋势。
- **季频份额申赎**：定期报告的期间申购 / 赎回 / 期末总份额 / 期末净资产。
- **国家队持仓预估**：预估份额 = 披露锚点 + 锚点后各季净申购 × 国家队占比；折合金额 = 预估份额 × 最新价。锚点可编辑、可按持有人结构一键推算。
- **数据本地留存**：份额 / 日频 / 季度 / 持有人 / 锚点五张本地表，再进页面只读本地快照渲染、零联网。

## 安装

前置：已安装 **[WHF 股票看板](https://github.com/WHF293/whf-stock-board)**。

1. 打开应用，进入「插件工坊」（应用内的插件管理入口）；
2. 选择「导入插件」，选中刚下载的 zip 安装包；
3. 导入后启用，左侧导航会出现「宽基跟踪」。

卸载：在「插件工坊」里对该插件点卸载，应用会询问是否一并删除本地数据表。

## 快速上手

1. 首次进入是空态 —— 点「**同步份额序列**」拉取宽基 ETF 的**逐日份额**（主口径）。首次会回填 2024-01-01 至今的历史（上交所按日全量、腾讯日 K 一次拿全窗口），后续只补缺失日期与最近 5 天，**已入库的不再回源**；
2. 份额卡给出组合总份额走势、每日估算净申赎柱状图与覆盖区间；信号卡按波段列出「疑似进场 / 疑似退场」；回测卡给出各信号的胜率与持有期收益；
3. 点「**刷新日频**」补充二级市场资金流与行情（辅助列，约 29 次串行请求）；点「**同步季度**」拉取份额申赎与持有人结构（持仓预估的输入）；
4. 持仓预估卡给出宽基口径合计的预估持仓与较锚点变动；点「编辑锚点」可校正锚点（按定期报告披露）或一键按持有人结构推算；
5. 明细表逐只展示最新价 / 涨跌幅 / 成交额 / 当日与近 5 日主力净流入 / 期末份额 / 季净申购 / 净资产 / 预估持仓。

> 💡 **份额序列是本插件的主口径**，也是判断「国家队建仓 / 退场」最直接的证据：二级市场资金流只能看出「大单在买」，而份额变动是**真实的一篮子申赎**。

## 数据与隐私

- **数据来源**：
  - **交易所官方披露（主口径）** —— 上交所 `query.sse.com.cn/commonQuery.do`（单日全市场 924 只 ETF 的份额，沪市 11 只在清单内）、深交所 `fund.szse.cn/api/report/ShowReport/data`（`CATALOGID=fund_jjgm`，深市 6 只在清单内）；
  - **腾讯行情** —— `web.ifzq.gtimg.cn/appstock/app/kline/kline`（不复权日 K 收盘价，用于把份额变动折算成金额）；
  - **东方财富与新浪**（辅助列）—— 行情快照与每日资金流（`push2delay.eastmoney.com`）、季度份额申赎与持有人结构（`fundf10.eastmoney.com` F10）、日 K 成交量（`quotes.sina.cn`）。
- **联网时机**：**只由你点击触发**（「同步份额序列」/「刷新日频」/「同步季度」/ 锚点相关操作），不轮询。
- **本地存储**：结构化数据落在插件的五张本地数据表 —— `plugin_dsh_broad_track_etf_share_daily`（**逐日份额**，唯一键 date+code）、`plugin_dsh_broad_track_etf_daily`（日频资金流与行情）、`plugin_dsh_broad_track_etf_quarter`（季度份额申赎）、`plugin_dsh_broad_track_etf_holders`（持有人结构）、`plugin_dsh_broad_track_anchor`（持仓锚点）。
- **卸载影响**：卸载时应用会询问是否一并删除这些表；**插件 id 一个字都不能改** —— 改了就等于换了一批新表，历史数据全部失联。

### 关键口径

- **份额是「份数」不是「金额」**：净申赎金额需用当日收盘价折算（Δ份额 × 收盘价）。价格缺失时金额留 `null`（不是 0）。
- **组合指数 = 固定权重的 Laspeyres 价格指数**（基准日 = 100）：
  - 权重取**基准日市值占比**（份额 × 基准日收盘价），**不是份额占比** —— 低单价 ETF 份额天然更多，用份额权重等于系统性放大低价 ETF（实测 2026-06-25 组合指数比沪深300实际涨幅高出 69 个点 vs 市值权重的 42 个点）；
  - 每只 ETF 的价格**按基准日价格归一化**后再加权（510300 约 4 元、科创50ETF 约 1 元，绝对价格量级差 4 倍）；
  - 权重固定 → 指数只反映**纯价格变化**，与份额变动完全解耦（份额涨了但没成交，指数不动）。
- **信号按「方向段」归并，不按逐日**：一次持续数周的减持战役是**一次事件**，逐日触发会碎成几十段（实测退场信号曾碎成 42 段，胜率统计全失真）。份额**不变**的日子不打断方向段（国家队持有不动也是「持有」）。
- **回测按波段统计**：每个信号波段算一次样本，不按天重复计；收益 = 信号日到 N 个交易日后的组合指数涨跌幅。
- **非交易日跳过**：腾讯日 K 的日期集合即权威交易日历，用来裁剪上交所请求日期（上交所对非交易日返回空 `result`，白跑）。
- **⚠️ 份额变动是「全市场净申赎」，不是国家队专属**：散户 / 险资 / 联接基金同样计入。引擎用「连续多日 + 大额 + 指数位置」三个条件联合筛出「疑似国家队动作」，界面上标注为推定而非确证。

## 已知限制

- **定位声明**：只做资金流痕迹的归类与持仓粗估，**不含任何买卖指令**；国家队没有公开每日持仓，预估与真实持仓必然有偏差。
- **份额变动 ≠ 国家队专属**：逐日份额是**全市场净申赎**，散户 / 险资 / 联接基金都在里面。「进场 / 退场」是基于「连续大额申赎 + 指数位置」的**形态推定**，与真实操作必然有偏差。
- **分摊模型的粗糙处**：净赎回季按机构占比同比例分摊（国家队未必同比例赎回）；联接基金 / 险资的申赎也被计入分母。定期报告披露后应以披露数据校正锚点。
- **回测样本量小**：信号判定的位置条件用「距前高回撤」，只用截至信号日的历史（无未来数据）；但样本只有十几个波段，胜率仅供研究参考，不构成投资建议。
- **深市域可能不可达（已定位根因，2026-10-28）**：深交所 `fund.szse.cn` / `www.szse.cn` 在代理 TUN + fake-ip DNS 环境下整域断连 —— 代理把 `szse.cn` 分流到被深交所 WAF 拒绝的出口（境外节点），换客户端 / 换 TLS 栈 / 拿真实 IP 直连都绕不开（DNS 被 fake-ip 接管）。此时深市标的缺失、沪市仍完整，同步会给出明确告警。**修法在用户侧**：代理软件给 `szse.cn` 加直连规则（或临时关代理）后重新同步，断点续传自动回填。
- **成交额近似误差**：历史成交额为「成交量 × 收盘价」的校准近似，与交易所口径有百分之几差距，只用于异动倍数（比值）判定。
- **上游限速**：交易所与腾讯对高频请求会掐连接，取数层已做原地小步重试；连续失败时按单只 ETF 降级并推告警，不影响其余数据落库。

## 设计说明

**为什么份额口径是主口径？** 二级市场资金流只是「谁在买卖」—— 机构换手、量化对冲都会产生，噪音极大；而**份额变动是真实的申购 / 赎回**，必须通过一篮子实物申赎完成，只有大额资金（国家队这个体量）才做得到。2024-02 的 2800 点底部建仓、2026-01 的规模减持退场，在份额序列上都是清晰的方向段。

**为什么是「锚点 + 净申购分摊」而不是直接加总份额？** 国家队的持仓没有每日公开值，但它的动作有两个可观测出口：定期报告的前十大持有人 / 披露整理（锚点），以及报告期间宽基 ETF 的份额申赎（净申购）。把净申购按「机构持有比例 × 国家队占比」分摊到锚点上，就得到一条随季报滚动、口径透明、可手工校正的持仓曲线。所有输入（锚点份额、机构占比、国家队占比、净申购）都在页面上直出，不做黑箱打分。
