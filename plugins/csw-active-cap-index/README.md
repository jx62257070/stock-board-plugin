# 活跃市值与指数贡献（csw-active-cap-index）

一句话：一页两段式的市场结构看板 —— 上面是**指南针 0AMV 口径的活跃市值**（看资金活跃度趋势），下面是**通达信口径的指数贡献**（看指数涨跌是谁拉谁拖）。

左侧导航「活跃市值与指数贡献」进入，整页看板分上下两块。

## 上半部 · 活跃市值（0AMV 口径）

指南针 0AMV（活筹指数）的市场含义是「市场上活跃交易的那部分筹码的市值」，经典用法是看趋势：曲线向上 = 场外资金进场，向下 = 场内资金出逃，走平 = 关键位。本插件用可解释的近似口径复刻：

> **当日活跃市值 = 当日成交额 ≥ 门槛（默认 1 亿，可设置：5000万 / 1亿 / 2亿）的个股流通市值之和**

- **趋势曲线**：近 60 个交易日，活跃市值主线 + 5 日均线（虚线，对齐 0AMV 看均线的用法）；曲线数据逐日累积在本插件数据表（装上当天开始生长，攒够 2 个点出曲线），同一交易日盘中多次刷新取最新值
- **汇总卡**：今日活跃市值、活跃家数、活跃成交额（占两市实时总成交比）、曲线天数
- **活跃股榜单**：成交额 Top 100（带榜内比例条），低于门槛的行比例条置灰；列可排序，行点击打开个股详情

## 下半部 · 指数贡献（通达信口径）

个股对指数涨跌点数的贡献（总市值加权，与通达信「贡献点」公式一致）：

```
贡献点(i) = 涨跌幅(i)% × (总市值(i) ÷ 指数样本总市值) × 指数点位
```

- **指数切换**：上证指数 / 深证成指 / 创业板指
- **汇总卡**：指数点位与涨跌幅、实际涨跌点、样本总市值（权重归一分母）、候选样本数
- **对账行**：样本合计贡献 vs 指数实际涨跌点（覆盖率）+ 正负贡献家数
- **正负两榜**（通达信风格）：▲ 拉指数 Top 10 / ▼ 拖指数 Top 10，每行带涨跌幅、贡献点、贡献占比（|贡献点| ÷ |指数实际涨跌|），行点击打开个股

## 口径与近似（重要）

| 项 | 口径 |
| --- | --- |
| 活跃集合 | 当日成交额 ≥ 门槛（默认 1 亿），从成交额 Top 300 中筛选 |
| 活跃市值 | 活跃集合的**流通市值**合计（0AMV 的「活跃筹码市值」近似） |
| 趋势曲线 | 逐日快照本地累积（ctx.db），**从安装当天开始生长**，无历史回填 |
| 交易日判定 | 周一至周五且两市实时成交额 ≥ 1000 亿才记录；**法定节假日不识别**（当天若盘中刷新会记入一条低值点，属已知误差） |
| 贡献权重 | **总市值**（f20，对齐通达信/上证指数总股本口径）÷ 指数样本总市值（指数 ulist 的 f20） |
| 上证指数 | 沪市全样本精确口径 |
| 深证成指 / 创业板指 | **近似口径**：个股样本按代码前缀圈定（深市 = `00`/`30`，创业板 = `30`）。深证成指实际只有 500 只成分股，此处按深市全样本近似 |
| 贡献候选池 | 总市值 Top 200 ∪ 成交额 Top 300（去重）——覆盖「大市值低成交」与「中小市值大涨跌」两端 |

## 数据与频率

- **数据来源**：东财 clist（成交额榜 3 页 + 总市值池 2 页）+ 东财 ulist（三指数一次拿全），每轮 6 个轻请求，错峰 400ms；两市实时总成交额走宿主服务
- **可靠性**：每个请求 12 秒超时；push2delay 主域失败自动回落 push2；整轮失败后再重试一轮（最多 4 次尝试）——「部分数据未更新」只会在上游连续不可达时出现，下一轮刷新自动补齐
- **刷新**：进入页面自动拉一轮；右上角「刷新」手动触发；插件设置可开「交易时段自动刷新」（30 秒，宿主轮询调度器驱动，默认关闭）
- **本地存储**：交易日快照表 `plugin_csw_active_cap_index_daily_snapshots`（桌面端 SQLite / 浏览器端本地仿真）；卸载时应用会询问是否一并删除

## 依赖

需要宿主提供：`app:ui` / `app:format` / `app:polling` / `app:stock-open` / `app:http`。
`app:market-data` 为**可选**（缺失时占比显示 `--`，且趋势曲线的交易日判定退化为仅按周末过滤）。

## 已知限制

- 单页上游上限 100 条（实测），全市场翻页会触频率红线，故活跃集合来自 Top 300；
- 趋势曲线无历史回填（指南针 0AMV 有全历史，本插件从安装日起逐日累积）；
- 深证成指 / 创业板指为近似口径（见上表）；
- 贡献对账的覆盖率通常在 60%~85%（样本池约 500 只 vs 全市场 5500+，但市值加权下已覆盖绝大多数有效贡献）。
