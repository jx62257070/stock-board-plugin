# 大盘云图（dsh-dapanyuntu）

安装包从 [GitHub Release](https://github.com/jx62257070/tauri-plugin/releases) 下载，文件名形如 `dsh-dapanyuntu-<版本>.zip`（版本以 Release 页面为准）。

一句话：在应用里直接看第三方站点「大盘云图」（dapanyuntu.com）的 A 股板块 / 个股树图——整页 iframe 直嵌，数据与交互全部由原站提供，本插件不取数、不代理、不存任何本地数据。

## 功能特性

- **整页云图**：市场总览页头「大盘云图」按钮（或「板块热力」卡标题）进入，路径 `/heatmap` 沿用宿主历史路径，老书签直达；不入侧栏导航。
- **明暗主题跟随**：桌面客户端（Tauri）内嵌 iframe 的明暗主题自动跟随应用主题切换（依赖宿主在 dapanyuntu.com 域名下注入的桥接脚本）；纯浏览器 dev / 移动端无注入机制，主题同步静默失效（原站保持自身默认暗色）。
- **访问原站**：页顶提示条声明内容来源，并提供「访问原站」按钮（经宿主 `app:open-url` 服务用系统默认浏览器打开；宿主过旧、服务缺席时按钮自动隐藏）。
- **来源声明**：提示条注明本页为第三方嵌入展示，数据与交互均由原站提供。

## 口径与边界

- 云图内容、板块口径、交互（缩放 / 下钻 / 搜索）全部由 dapanyuntu.com 自管；若对方日后加嵌入限制或域名不可达，页面表现为空白 —— **停用本插件即可**，不影响应用其他功能。
- 主题同步的 postMessage 信源常量 `'whf-stock-board'` 与宿主 Rust 注入脚本（`HEATMAP_THEME_INIT_SCRIPT`）三端约定，任一端改动必须同步。

## 安装

前置：已安装 **[WHF 股票看板](https://github.com/WHF293/whf-stock-board)**（v4.27.0 起，旧版本宿主页面内置、无需安装）。

1. 打开应用，进入「插件工坊」→「插件清单」的「未安装 / 全部」视图（或「安装自定义插件」→「从 zip 包安装」选中下载的 zip）；
2. 安装后从市场总览页头「大盘云图」按钮进入。未安装时该按钮落到 404 引导页。

## 卸载

插件工坊里一键停用 / 卸载即可：本插件无 `ctx.db` 数据表、无持久化偏好，卸载即干净移除，无残留数据待处置。
